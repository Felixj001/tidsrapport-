Första gången — Konfigurera Supabase

Följ dessa steg en gång för att koppla databasen. Tar ca 5 minuter.

1
Skapa gratis Supabase-konto
Gå till supabase.com → Klicka "Start your project" → Logga in med GitHub eller e-post
2
Skapa ett nytt projekt
Klicka "New project" → Namnge det recondconcept → Välj region "EU West" → Skapa ett lösenord → Klicka "Create new project"
3
Skapa databastabellen
I Supabase → gå till SQL Editor → klistra in SQL-koden nedan → klicka "Run"
create table rapporter (
  id bigint primary key generated always as identity,
  skapad_at timestamptz default now(),
  datum date not null,
  projekt text, start_tid text, slut_tid text,
  rast_min int default 0, timmar numeric,
  beskrivning text, plats text, kund text,
  lunch text, traktamente text,
  km numeric default 0, fordon text,
  kommentar text, namn text, roll text, ansnr text,
  material jsonb default '[]',
  utrustning jsonb default '[]',
  user_id uuid references auth.users(id)
);
alter table rapporter enable row level security;
create policy "Inloggade kan se alla rapporter"
  on rapporter for select using (auth.role() = 'authenticated');
create policy "Kan skapa egna rapporter"
  on rapporter for insert with check (auth.uid() = user_id);
create policy "Kan radera egna rapporter"
  on rapporter for delete using (auth.uid() = user_id);
4
Hämta dina nycklar
I Supabase → Project Settings → API → Kopiera Project URL och anon public-nyckeln
⚠️ Skapa sedan ditt konto via Supabase → Authentication → Users → Invite user och bjud in dig själv och dina kollegor via e-post.
